| :--- | :--- | :--- | :---: | :--- |
| **ERA5 Header Metadata Rows** | Lines 1–3 contained station coordinates and timezone metadata, causing standard CSV parser failure (`ParserError: Expected 6 fields, saw 9`). | Programmatically extract metadata dictionary from lines 1–2; skip first 3 lines (`skiprows=3`) to load table header on line 4. | 17,544 rows | Clean DataFrame loading with separate geospatial station metadata dictionary. |
| **ERA5 Corrupted Column Headers** | Attribute names contained non-ASCII symbols and units (`temperature_2m (°C)`, `relative_humidity_2m (%)`, `soil_moisture_0_to_7cm (m³/m³)`). | Standardize column names into snake_case lowercase English identifiers (`temp_2m_c`, `rh_2m_pct`, `soil_moist_0_to_7cm_m3m3`). | 17,544 rows (9 columns) | 100% ASCII-compliant column schema ready for parquet serialization. |
| **ERA5 Implicit Timezone & Datetime String** | Hourly timestamps formatted as ISO-8601 strings without explicit UTC synchronization (`2023-01-01T00:00`). | Parse string to `datetime64[ns]`, assign `timestamp_local` (GMT-6), and derive explicit `timestamp_utc` (+6 hours). | 17,544 rows | Synchronized dual-temporal reference frame for satellite fusion. |
| **NASA FIRMS Disconnected Date & Time** | Satellite detection dates (`acq_date` e.g. `'2023-05-12'`) and scan times (`acq_time` e.g. `820` or `1430`) stored in separate columns. | Zero-pad `acq_time` to 4 digits (`0820`), format as `HH:MM:SS`, concatenate with `acq_date` and cast to `datetime64[ns]` UTC. | 657,791 detections | Single unified `timestamp_utc` column enabling temporal window joins. |
| **NASA FIRMS Abbreviated Categorical Labels** | Confidence and satellite pass flags encoded as cryptic single characters (`confidence: 'l', 'n', 'h'`, `daynight: 'D', 'N'`). | Map values to descriptive categories: `'low', 'nominal', 'high'` and `'Day', 'Night'`. | 657,791 detections | Self-documenting categorical attributes. |
| **NASA FIRMS Scan Duplicates & Geographic Outliers** | Repeated orbital scan overlaps and edge detections outside Mexico's sovereign territory. | Filter latitude to $[14.0^\circ\text{N}, 33.5^\circ\text{N}]$ and longitude to $[-118.5^\circ\text{W}, -86.0^\circ\text{W}]$; deduplicate by `(latitude, longitude, timestamp_utc)`. | 3,142 records nationwide | Eliminates unphysical coordinates and artificial duplicate fire detections. |
| **CONAFOR Spanish Encoding & Special Characters** | Column headers contained corrupted ISO-8859/Windows-1252 characters (`'Ao'`, `'Herbceo'`, `'Rgimen de fuego'`, `'Total hectreas'`). | Rename all 37 columns to standardized snake_case identifiers (`anio`, `fire_id`, `stratum_herbaceo_ha`, `total_hectareas`, etc.). | 101,003 records (37 columns) | Fully clean columnar identifiers compatible with Parquet and Arrow schemas. |
| **CONAFOR Positive Longitude Sign Discrepancies** | Longitude coordinates recorded with positive signs (e.g. `102.63` instead of `-102.63`), placing coordinates in Asia/Indian Ocean. | Check `longitude > 0` condition across Mexican coordinates and multiply by `-1.0`. | 48 records | Restores coordinates to the Western Hemisphere within Mexican territory. |
| **CONAFOR Unmappable Spatial Coordinates** | Missing or out-of-range coordinates (`latitude` null or $< 14^\circ$, `longitude` null or $> -86^\circ$). | Drop unmappable records lacking valid geographic coordinates after logging. | 2 records | 100% of retained historical records are spatially mappable. |
| **CONAFOR Missing Strata Hectares** | Null values present in vegetative stratum impact columns (`stratum_arbolado_adulto_ha`, `stratum_renuevo_ha`, `stratum_arbustivo_ha`). | Explicitly impute `NaN` values to `0.0` ha, reflecting zero affected surface in that stratum. | 32 records | Preserves record integrity without arbitrary statistical bias. |
| **CONAFOR Missing Vegetation Classification** | 946 historical fire events lacked categorical forest vegetation classification (`tipo_vegetacion = NaN`). | Impute missing categories with explicit token `'No Especificado'`. | 946 records | Prevents silent record deletion while maintaining audit transparency. |
| **CONAFOR Duplicate Fire Keys** | Duplicate entries sharing identical official `Clave del incendio` (`fire_id`). | Identify duplicates and retain the primary official entry, discarding secondary duplicates. | 14 records | Ensures primary key uniqueness across the ground-truth table. |
